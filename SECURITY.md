# Security Policy

## Supported versions

Security fixes are applied to the latest published release of the extension.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:

https://github.com/bozduran/jrxml-editor-extension/security/advisories/new

Do not open a public issue for a security report. Include the affected version,
reproduction steps, and any relevant JRXML sample in the advisory.

## Scope

This extension reads JRXML files and runs an extension-host and webview process.
Reports about expression handling, webview isolation, resource loading, or the
release toolchain are in scope. JasperReports compiler, fill, and export issues
belong to the upstream JasperReports project.
